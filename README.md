## Final Project

The final project is the **Eternal Quest Goal Manager**, a C# console application that allows users to create, manage, and track different types of goals while earning points and progressing through achievement ranks.

The program demonstrates the core principles of object-oriented programming by using abstraction, encapsulation, inheritance, and polymorphism. It also includes file saving and loading, allowing users to preserve their progress between sessions.

## Example

**Features include:**

- Create multiple goal types
- Record completed goals
- Earn points for achievements
- Save and load progress from files
- Achievement ranking system
- Object-oriented design using inheritance and polymorphism

## How to Run the Program

1. Make sure the .NET SDK is installed on your computer.
2. Open the project folder in Visual Studio or Visual Studio Code.
3. Open the terminal in the project directory.
4. Run the program
5. Follow the on-screen prompts to interact with the application.
